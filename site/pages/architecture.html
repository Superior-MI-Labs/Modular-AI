ENGINEERING BLUEPRINT / VERSION 0

Small core. Replaceable experiments.

The framework should be flexible without becoming a second AI framework for every model. Establish permanent contracts, then vary model modules and training strategies behind them.

RECOMMENDED APPROACH

Ports, adapters and a typed execution graph

One registry identifies module implementations. A manifest selects modules. The validator checks semantic and artifact compatibility before a workflow executes.

Use Strategy for interchangeable policies, Factory/Registry for selection, and Ports and Adapters to keep framework dependencies outside the core. The typed graph connects the contracts; it should not own model-specific algorithms.

StableVersioned contract definitions, orchestration, lineage
ReplaceablePolicies, encoders, tokenizers, models, samplers, backends
THE BOUNDARY THAT MATTERS

Swappable does not mean interchangeable.

SAFE WITH COMPATIBLE CONTRACTS

Selection at run boundaries

Exchange one deterministic policy for another with the same observation and action semantics. Replace evaluation metrics or dataset loaders when contracts match.

NEEDS VALIDATION OR RETRAINING

Representation changes

New token vocabularies can invalidate embedding weights. Changed latent codecs can invalidate denoisers. A VAD state encoder needs a policy trained or designed for that representation.
