OPEN DEVELOPMENT / RESEARCH-FIRST

Build the foundation before the complexity.

We have an architecture atlas and example manifests. We do not yet have an executable modular AI runtime. The milestones below make that distinction visible.

00 DOCUMENTED

Website, diagrams and design validation

Dark blueprint diagrams, seven learning/site pages, a read-only module lab, versioned reference examples and a shared Python compatibility prototype. No runtime yet.

Reference contractsStatic explorerAudit
01 NEXT

Typed contracts and immutable manifests

Promote conceptual port strings into typed, versioned schemas; define module capabilities and real artifact fingerprints; secure factory resolution and manifest hashing.

Exit test

Reject invalid representations and artifacts before constructing any model.

02 PLANNED

Minimal executor and decision baseline

One isolated workflow runner, explicit execution context, toy episode environment and two independently implemented policies.

Exit test

Configuration-only swaps, reproducible episodes, strict cancellation and state scope.

03 PLANNED

Cross-family workflows and artifacts

Reference token, iterative, training and transform controllers. Tiny CPU training, checkpoint/resume, immutable artifact lineage, failure records and tested plugin boundary.

Exit test

Run the eight core gates before tagging core-v1.0.

04 CORE FREEZE

Core complete v1

Freeze documented public contracts after passing reproducibility, extension, lifecycle and migration tests. Future workflow controllers implement the same stable interface.

Exit test

Install an independent workflow/module package with no changes to core files.

05 AFTER FREEZE

Text, image, video and optimization modules

Custom tokenizers, trained decision models, diffusion and flow models, video generation, LoRA, distillation and quantizers. Each reports checkpoints, resources, quality and compatibility.

Exit test

New capabilities use frozen contracts; breaking changes require an explicit core revision rather than a hidden shim.
