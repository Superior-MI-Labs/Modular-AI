OPEN DEVELOPMENT / RESEARCH-FIRST

Build the foundation before the complexity.

We have an architecture atlas and example manifests. We do not yet have an executable modular AI runtime. The milestones below make that distinction visible.

00 DOCUMENTED

Architecture atlas and website

Diagram sources, SVG exports, site navigation, architecture decisions, example manifests and acceptance-test planning.

Visual learningVersioned conceptsDocumentation
01 NEXT

Contracts and deterministic decision baseline

Implement a minimal registry, configuration validation, typed ports, a toy environment and two compatible decision policies. Reject incompatible state representations.

Exit test

Swap policies through configuration alone, reproduce an episode, and reject invalid swaps before execution.

02 PLANNED

Trainable neural reference model

Add one simple data pipeline, model, objective, optimizer and checkpoint path. Preserve a single source of truth for parameter and artifact metadata.

Exit test

Train, save, reload and reproduce predictions with a fixed seed.

03 PLANNED

Representation experiments

Tokenizers, feature vectors, state and memory encoders, and migration tests. Changes that break checkpoint compatibility must be explicit.

04 PLANNED

Evaluation, optimization and deployment

Benchmarking, precision changes, quantization, pruning, distillation and model artifact lineage.

05 FUTURE

Image, audio and video families

Add family-specific loops only when shared contracts and the core have proven useful. Focus on clear diagnostics and comparable experiments.

Want to contribute?

Start with a diagram, documentation correction, test case or compatibility contract. The project favors observable evidence and small, durable abstractions over feature count.
